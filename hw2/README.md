# Homework 2 — Selection via Proxy

В этом задании исследуется метод **Selection via Proxy (SVP)** — отбор части обучающих данных с помощью proxy-модели, чтобы уменьшить объём данных для обучения целевой модели.

## Что внутри

- `cifar/` — эксперименты на CIFAR-10 и CIFAR-100.
- `amazon/` — эксперименты на данных о товарах и отзывах Amazon.
- `results/` — сохранённые результаты экспериментов (если папка присутствует).
- `hw2_reproduction_report_ru.md` — отчёт с описанием экспериментов и выводами.

## Основные эксперименты

- **CIFAR-10:** сравнение случайного отбора, Forgetting Events и Entropy.
- **CIFAR-100:** сравнение длительности обучения proxy-модели (25, 50 и 100 эпох)
- **Amazon:** проверка метода на признаках товаров и текстовых эмбеддингах отзывов, подготовленных в рамках проекта Amazon Audit Service.

## Запуск

Код рассчитан на Python и зависимости, используемые в соответствующих скриптах проекта. Запускайте нужный эксперимент из корневой папки репозитория или из папки соответствующего набора данных. Конкретные параметры экспериментов указаны в самих скриптах.

## Результаты

Основные метрики, графики и ограничения экспериментов описаны в отчёте. Для эксперимента с корреляцией Спирмена не удалось получить надёжную итоговую матрицу, поэтому выводы следует рассматривать с учётом ограничений, указанных в отчёте.
